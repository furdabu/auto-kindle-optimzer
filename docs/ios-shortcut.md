# iOS ショートカットの設定

iPhone / iPad の共有シート（Share Sheet）から PDF を本ツールへ送信するためのショートカットを作成します。これにより、Safari や他アプリで開いた PDF を「共有」→ ショートカット実行 だけで Kindle に配信できます。

## 前提

- サーバーが起動済みで、iPhone から到達できること
  - 同一 LAN: `http://<サーバーのローカルIP>:3847`
  - Tailscale 等: `http://<Tailscaleホスト名>:3847`
- `.env` の `API_TOKEN` を控えておくこと

## 作成手順

1. ショートカットアプリを開き、右上の「+」で新規ショートカットを作成する
2. アクションを追加: 「**URLの内容を取得**」（Get Contents of URL）
3. URL に次を入力する

   ```
   http://<サーバーのIPまたはホスト名>:3847/api/jobs
   ```

4. 「詳細を表示」を展開し、以下を設定する
   - **方法 (Method)**: `POST`
   - **ヘッダ (Headers)**: 新規追加
     - キー: `Authorization`
     - 値: `Bearer <API_TOKEN>`（`.env` の値に置き換える）
   - **要求の本文 (Request Body)**: `フォーム` (Form)
   - 「新規フィールドを追加」→ タイプを **ファイル (File)** にする
     - キー: `file`
     - 値: 「**ショートカットの入力**」（Shortcut Input）を選択
5. （任意）レスポンスを確認したい場合は、続けて「**辞書の値を取得**」で `jobId` を取り出し「**通知を表示**」で表示する

## 共有シートに表示する

1. ショートカット下部の情報アイコン（ⓘ）をタップ
2. 「**共有シートに表示**」(Show in Share Sheet) をオンにする
3. 「共有シートのタイプ」で **PDF** と **ファイル** を有効にする
4. 右上の「完了」を押す

## 使い方

1. PDF を開く（Safari / ファイル / メール等）
2. 共有ボタンをタップ
3. 一覧から作成したショートカットを選択して実行
4. 数分後、変換された EPUB が Kindle 端末に届く

## うまくいかないとき

- **401 が返る**: `Authorization` ヘッダの `Bearer ` の後ろのトークンが `.env` の `API_TOKEN` と一致しているか確認
- **接続できない**: サーバーの IP / ポートが正しいか、iPhone とサーバーが同じネットワーク（または VPN）にいるか確認
- **Kindle に届かない**:
  - `SMTP_FROM` が Amazon の「承認済み Eメールアドレス一覧」に登録されているか確認
  - 変換後ファイルが 50MB を超えていないか確認（KCC のオプションでサイズを抑える）
  - `GET /api/jobs/<jobId>` でジョブの `status` と `error` を確認
